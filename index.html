turn-taking instrument

Turn Lag

Paste a conversation transcript and see the rhythm underneath it: who talks when, how long the gaps between turns run, and where turns overlap. Then simulate call delay on one speaker and watch the same conversation's timing statistics shift. Built on floor-transfer-offset (FTO) methodology from conversation-timing research — the same measure used to study how audio/video-call latency distorts turn-taking. Runs entirely in your browser; nothing you paste is uploaded anywhere.

Two separate recordings of the same call, one per person — each file should contain only that speaker's turns. Any speaker tags already inside the file are ignored and replaced with the name you give it below. Timestamps in both files need to share the same starting point (both counted from when the call began).

WebVTT & SRT format

Standard export from Zoom, Otter, or most caption and diarization tools. Speaker can be tagged as <v Name>, [Name]:, or plain Name: at the start of the cue.

1
00:00:03,254 --> 00:00:04,175
[SPEAKER_01]: What's your favorite movie?

2
00:00:06,299 --> 00:00:11,667
[SPEAKER_00]: I have a pretty bad memory.

CSV format

Columns speaker, start, end, text (speaker and text both optional — a speaker column isn't needed for a single-speaker track file). Times can be seconds or mm:ss / hh:mm:ss.mmm.

speaker,start,end,text
Alice,0:00,0:02.5,"Hey, how's it going?"
Bob,0:02.3,0:04.1,Pretty good
